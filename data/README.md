# Data

В проекте используется учебный датасет `new_games.csv` с историческими данными о видеоиграх, платформах, жанрах, региональных продажах, оценках и рейтингах ESRB.

Исходный CSV не включён в репозиторий. Ноутбук сначала ищет файл локально по пути `data/new_games.csv`, а при его отсутствии загружает данные из открытого источника Яндекс Практикума.

Основные поля: `name`, `platform`, `year_of_release`, `genre`, `na_sales`, `eu_sales`, `jp_sales`, `other_sales`, `critic_score`, `user_score`, `rating`.
